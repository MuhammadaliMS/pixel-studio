Make your own in three steps

You need Claude Code and Node. That's it: no installs, no build step, no dependencies.

Get the studio

Clone the repo and give Claude the Pixel Studio skill.

git clone https://github.com/MuhammadaliMS/pixel-studio
cd pixel-studio
mkdir -p ~/.claude/skills/pixel-studio
cp skill/SKILL.md ~/.claude/skills/pixel-studio/

Ask Claude for a scene

Open Claude Code in the folder and describe what you want to see.

claude "make a pixel video of the Eiffel
Tower melting in a heatwave, ember palette"

Export the video

Render the loop to an MP4, with sound, ready for Reels, TikTok or Shorts.

node tools/render.mjs scenes/eiffel.js \
  --mp4 out/eiffel.mp4

Why it looks right

The engine enforces the rules pixel artists follow, so Claude can't make blurry, generic AI art.

Tiny canvasDrawn at 256×320, then scaled up with no smoothing. Every pixel stays crisp.
Palettes, not coloursPixels store colour numbers, so one click recolours a whole scene.
DitheringSmoke, glow and shadows use checker patterns instead of blurry transparency.
12 fpsMotion steps like hand-drawn animation. Physics is precomputed, so every frame is exact.
Outlines + shadingCharacters get lit, rounded shading and a crisp outline, so they pop.
Synth soundEvery tick, crack and boom is generated in code. No audio files needed.
